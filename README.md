# Mamadou Adama Diallo — Portfolio

Personal portfolio site for Mamadou Adama Diallo. Static HTML, CSS, and JavaScript — ready for GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000`.

## Deploy (GitHub Pages)

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root (`/`)
